# Changelog

## 2.7.1 — initial GitHub distribution

Existing signed publication APK, versionCode 15. GitHub packaging does not change the binary or add features.

- Separate named shared-folder roots and download history.
- Messages, call history/status, local Chat, QR pairing and local HTTPS.
- Permission-dependent navigation, SIM views/names, battery display and appearance controls.
- Existing dedicated release signing retained.

Experimental 2.8 features are excluded. No historical release dates are invented.
